# Relay network

## Overview
A chain of crewed stations that passes signals across the Reach in hours
rather than years.

## How it works
Each station takes the signal from the one before it and passes it on, so
one silent station cuts off everything behind it until traffic is rerouted.

## Limits
A station needs a crew of about thirty, and a working access code from
Command to change anything.

## Consequences
The Compact can only exist because of it.

### What the signal did
<!-- wolfden: from=ash:5 -->
It devastated the Velari when it was first lit. See [[velari-plague]]. The
stations going silent now may be connected, but nobody knows how yet.
